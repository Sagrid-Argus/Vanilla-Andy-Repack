# VANILLA ANDY

### The Ultimate Vanilla Experience

> **Pure Vanilla. Pure Suffering.**

**Vanilla Andy** is a ready-to-use **World of Warcraft Vanilla 1.12.1 repack**, designed primarily for local play, testing and preservation of the original Vanilla experience.

No custom content. No modern systems. No Classic+ philosophy.

Just **patch 1.12.1**, as it was meant to be.

## Features

* World of Warcraft **1.12.1**
* Pre-configured server environment
* Ready-to-use databases
* Authentication and world servers
* Pre-configured local setup
* Pre-created **Andy** character
* **1000 level 1 PlayerBots** joining Andy at server start
* Designed for easy local deployment
* Can be opened to friends with a few database and network configuration changes

## The Fresh Server Experience

When the server starts, **Andy and 1000 PlayerBots begin their journey at level 1**.

Everyone starts from scratch. Everyone is poor. Everyone is killing wolves. Everyone is running around with terrible gear.
For a brief moment, your local server becomes the freshest Vanilla server on Azeroth.

> **1,000 players online.**
>
> **0 players above level 1.**
>
> **It's launch day.**

The only difference is that they're all running on your computer.

## Getting Started

The repack is intended to be as straightforward as possible:

1. Set up the included server files.
2. Start the server.
3. Launch a compatible **WoW 1.12.1 client**.
4. Log in with the included account.

```text
Username: Andy
Password: Andy
```

The **Andy** character is already created and waiting for you.

He is level 1. He is wearing his starter gear. He has his hammer. And now he has **1,000 friends**.

## Local Server

Vanilla Andy is primarily intended to be played **locally**, either alone or for development and testing purposes.
With a few changes to the database and the appropriate network configuration, the server can also be made accessible to friends for private multiplayer sessions.
The repack does not aim to provide a public-server infrastructure out of the box. It is meant to give you a simple, self-contained Vanilla environment that you can run on your own machine.

## Philosophy

Vanilla Andy follows a simple rule:

> **If it wasn't in Vanilla 1.12.1, it isn't here.**

This is not Vanilla+. This is not Classic+. This is not Vanilla with modern quality-of-life features.
It is an attempt to keep the original 1.12.1 experience intact, while making the process of running a private Vanilla server considerably less painful.
